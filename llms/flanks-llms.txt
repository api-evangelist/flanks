# Flanks

> Flanks is an AI-powered wealth data platform that aggregates and standardizes investment and banking data from 700+ financial institutions into a unified model for financial advisors, banks, family offices, and asset managers. The Flanks API exposes the Connect flow (link accounts, resolve MFA/SCA), credential and entity management, and aggregation of portfolios, investments, accounts, liabilities, and cards. A hosted Model Context Protocol (MCP) server gives AI assistants direct, OAuth-secured access to the same investment data.

## APIs
- [Flanks API Documentation](https://docs.flanks.io/): Developer docs for the Flanks Connect, Entities, Credentials, Aggregation, and Letters APIs.
- [Authentication](https://docs.flanks.io/pages/flanks-apis/authentication/): OAuth2 client-credentials; token endpoint https://api.flanks.io/v0/token.
- [Connect API v2](https://docs.flanks.io/pages/flanks-apis/connect-api/v2/): Base https://api.flanks.io/connect/v2 — connectors, sessions, SCA resolution.
- [Entities API](https://docs.flanks.io/pages/flanks-apis/entities-api/)
